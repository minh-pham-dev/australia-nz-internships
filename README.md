# 🇦🇺 Australian Tech Internships & Grad Programs: International Student Friendly

A free, community list of **software, data and IT internships and graduate programs in Australia**, showing for every role:

- **Can international students apply?** Quoted straight from the job ad, so you don't waste an application.
- **Does the company sponsor visas?**
- **When does it open and close?** Big companies hire 9–12 months ahead, so the dates matter.

Built by a Deakin CS student who got tired of opening ads only to read *"citizens and permanent residents only"* at the bottom.

> ⭐ Star the repo to keep it handy. 🙌 Spotted a new role or a mistake? [Open an issue](../../issues/new/choose) or read [CONTRIBUTING.md](CONTRIBUTING.md).

## Legend

| Symbol | Meaning |
|---|---|
| ✅ Yes | Student visa holders can apply |
| ❌ No | Citizens / permanent residents only |
| ⚠️ Conditional | Depends on work rights, office or team (see the quote) |
| ❓ Unknown | The ad doesn't say. Check with the employer |
| 🛂 Yes | The company says it sponsors visas for this role |

## Important

- This list is **not affiliated with any employer or university**.
- Eligibility rules change every year. **Always read the official ad before applying.**
- Nothing here is migration advice. Check your own visa conditions on [VEVO](https://immi.homeaffairs.gov.au/visas/already-have-a-visa/check-visa-details-and-conditions) and the [Home Affairs website](https://immi.homeaffairs.gov.au/).

## How it works

The table above is generated from [`data/listings.yml`](data/listings.yml) by a small Python script:

```bash
pip install pyyaml
python3 scripts/generate_readme.py
```
