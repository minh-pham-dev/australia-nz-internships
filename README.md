- Most 2027/28 programs **haven't opened yet**. Each row shows when it's expected to open. Where there's a ▶ arrow, click it to see when last year's round opened.
- Until then, the **"International students?"** column is based on **last year's (2026/27) ad**.
- Click it for a short explanation and a link to the ad. We update each row as soon as its 2027/28 ad comes out.

## 🔑 Legend

|---|---|
| ⏳ Not open yet | Shows when it's expected to open |
| 📝 Open | Apply now |

| International students? (2026/27) | Meaning |
|---|---|
| ✅ Yes | Student visa holders could apply |
| ❌ No | Citizens and permanent residents only |
| ⚠️ Depends | Depends on work rights, office or team. Click to read |
| ❓ Not stated | Not mentioned in the ad. Check with the employer before applying |

## ⚠️ Important

- Not affiliated with any employer or university.
- Rules change every year. **Always read the official ad before applying.**
- When a company has taken last year's ad down, the source link goes to an exact copy of it on another job board.
- Nothing here is migration advice. Check your own visa conditions on [VEVO (Australia)](https://immi.homeaffairs.gov.au/visas/already-have-a-visa/check-visa-details-and-conditions) or with [Immigration New Zealand](https://www.immigration.govt.nz/).

## 🛠️ How it works

The tables are generated from [`data/listings.yml`](data/listings.yml):

```bash
pip install pyyaml
python3 scripts/generate_readme.py --check   # validate the data
python3 scripts/generate_readme.py           # rebuild the tables
```
